# Workflow: Code Review

## Purpose
Perform senior engineer code review on recent commits, changed files, or pending feature branches.

## Workflow Steps

1. **Diff Inspection**:
   - Inspect git status, git diff, or modified files.
2. **Review Execution**:
   - Invoke `code-review` skill across functional correctness, architecture, security, performance, and test coverage.
3. **Report Findings**:
   - Document findings categorized by severity with explicit line links and remediation guidance.
