# Workflow: Refactor

## Purpose
Refactor existing code safely while preserving runtime behavior.

## Workflow Steps

1. **Establish Test Baseline**:
   - Run existing unit test suite to verify baseline functionality.
2. **Execute Refactoring**:
   - Invoke `refactoring` skill to perform incremental, behavior-preserving code restructuring.
3. **Continuous Verification**:
   - Run tests after each incremental change.
4. **Final Review & Report**:
   - Document structural improvements and test confirmation.
