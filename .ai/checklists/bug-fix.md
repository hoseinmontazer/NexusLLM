# Checklist: Bug Fix

- [ ] Failure log / traceback collected and analyzed.
- [ ] Reproducing test case created.
- [ ] Finding Validation Gate executed prior to writing fix.
- [ ] Root cause verified (not a false positive or framework artifact).
- [ ] Minimal fix implemented without swallowing exceptions or deleting tests.
- [ ] Reproducing test case re-run and passing.
- [ ] Full regression suite executed and passing.
- [ ] Standard final report generated with empirical test evidence.
